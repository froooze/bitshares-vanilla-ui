# Italian glossary — `bitshares-vanilla-ui`

This is the file an external auditor reads **before** trusting a machine-filled
Italian translation. It fixes **one Italian term per concept**, so a single
correction here (plus the same word in `vanilla/locales/it.json`) propagates
everywhere instead of leaving three near-synonyms in the UI.

**How to use it**

- Translate the English term in column 1 as the Italian term in column 2. Do not
  invent a second Italian word for the same concept: a synonym split is the one
  mistake this file exists to prevent.
- Column 3 says why, and names the `it.json` keys that already prove the
  wording. Keys cited there were read out of `vanilla/locales/it.json` after the
  2026-10-13 fill pass; a citation is evidence, not decoration. In the notes,
  an Italian WORD in bold is a form under discussion, not a locale key — only
  things shaped like `section.key` are citations.
- Corrections land through the `translation` issue label on the project tracker —
  the same route `#/help/translation-limitations` in the wallet gives readers.
- **Status:** the Italian column below is the agreed vocabulary, not yet a claim
  of human review. The Italian fill pass cross-checked every row against
  `it.json` and chose the form that file actually uses. Until a person has read
  a string in Italian, the wallet labels it machine-filled.
- **Every row names the form `it.json` uses.** Where a second form exists for
  the same concept, the row lists **every** string carrying it — as a
  counter-example (align it on the next pass) or as a same-root other sense
  (leave it alone). A glossary that breaks a dozen correct pool strings is worse
  than no glossary.
- **Typography follows the section, not the string.** `it.json` writes the
  typographic apostrophe (U+2019) in `about`, `apilab`, `createaccount`,
  `createworker`, `dashboard`, `debit`, `eslab`, `fees`, `news`, `notify`,
  `password`, `referrals`, `samet`, `settings`, `ticket`, `topops`, `tour`,
  `uri`, `wallet`; every other section writes the ASCII apostrophe. So the ASCII
  and the typographic spelling of the same phrase are the **same word** — do not
  "fix" one into the other. The split is pre-existing, deliberate, and asserted
  by `tooling/apply_i18n_it_chunkA.py` and `tooling/apply_i18n_it_chunkB.py`
  (gate G7, read from the shipped file rather than a hand-kept list).

Placeholders (`%(name)s`), URLs, object ids (`1.2.x`), asset symbols and theme
or network ids are **byte-verbatim** in every language and never appear here.
