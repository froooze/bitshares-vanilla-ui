# Turkish glossary — `bitshares-vanilla-ui`

This is the file an external auditor reads **before** trusting a machine-filled
Turkish translation. It fixes **one Turkish term per concept**, so a single
correction here (plus the same word in `vanilla/locales/tr.json`) propagates
everywhere instead of leaving three near-synonyms in the UI.

**How to use it**

- Translate the English term in column 1 as the Turkish term in column 2. Do not
  invent a second Turkish word for the same concept: a synonym split is the one
  mistake this file exists to prevent.
- Column 3 says why, and names the `tr.json` keys that already prove the wording.
  Keys cited there were read out of the shipped `vanilla/locales/tr.json`. A
  citation is evidence, not decoration: in the notes, a Turkish WORD in **bold**
  is a form under discussion, not a locale key — only things shaped like
  `section.key` are citations.
- "N strings" means: N keys of `tr.json` whose value differs from `en.json` and
  contains the Turkish word, counted on the shipped file. A count is a smoke
  alarm for a synonym split, not a definition.
- Corrections land through the `translation` issue label on the project tracker —
  the same route `#/help/translation-limitations` the wallet gives readers
  (`help.topic_translation-limitations_title` "Çeviri sınırları").
- **Status:** the Turkish column below is the agreed vocabulary, not yet a claim
  of human review. Until a person has read a string in Turkish, the wallet labels
  it machine-filled (`i18n.badge_body` "Bu çeviriler bir makine tarafından
  oluşturuldu ve insan denetiminden geçmedi.") and every signing line marked `*`
  shows the English one tap away (`i18n.risk_show_english` "Bu satırın İngilizce
  karşılığını gösteriniz").
- **Every row names the form `tr.json` uses.** Where a second form exists for the
  same concept, the row lists **every** string carrying it — as a counter-example
  (align it on the next pass) or as a same-root other sense (leave it alone). A
  glossary that breaks a dozen correct voting strings is worse than no glossary.
  Every count and every key below is machine-verified against the shipped
  dictionary by `tooling/i18n-glossary-multi-test.js`.
- **Register.** `tr.json` is a formal second-person register: the reader is
  **siz** (`about.hero_lede` "Anahtarlarınız bu tarayıcıdan asla çıkmaz."), and
  instructions use the polite imperative. Keep the dotted and dotless i exactly
  as shipped — `ihraççı`, `teminat`, `işlem`, `ödünç` — do not "modernise" a
  spelling that the dictionary already fixed.
- **Loanwords are translated.** `swap` and `proxy` are **not** left in Latin
  here: the dictionary writes takas and vekil and contains zero Latin
  occurrences of either word. HTLC alone stays Latin, as in every other locale.

Placeholders (`%(name)s`), URLs, object ids (`1.2.x`), asset symbols and theme
or network ids are **byte-verbatim** in every language and never appear here.
