# German glossary — `bitshares-vanilla-ui`

This is the file an external auditor reads **before** trusting a machine-filled
German translation. It fixes **one German term per concept**, so a single
correction here (plus the same word in `vanilla/locales/de.json`) propagates
everywhere instead of leaving three near-synonyms in the UI.

**How to use it**

- Translate the English term in column 1 as the German term in column 2. Do not
  invent a second German word for the same concept: a synonym split is the one
  mistake this file exists to prevent.
- Column 3 says why, and names the `de.json` keys that already prove the wording.
  Keys cited there were read out of `vanilla/locales/de.json` as shipped. A
  citation is evidence, not decoration: in the notes, a German WORD in **bold**
  is a form under discussion, not a locale key — only things shaped like
  `section.key` are citations.
- "N strings" below means: N keys of `de.json` whose value differs from
  `en.json` and contains the German word, counted case-insensitively on the
  shipped file. A count is a smoke alarm for a synonym split, not a definition.
  Every count and every citation in this file is checked mechanically against the
  shipped dictionary by `tooling/i18n-glossary-multi-test.js`.
- Corrections land through the `translation` issue label on the project tracker —
  the same route `#/help/translation-limitations` in the wallet gives readers.
- **Status:** the German column below is the agreed vocabulary, not yet a claim
  of human review. The German fill cross-checked every row against `de.json` and
  chose the form that file actually uses. Until a person has read a string in
  German, the wallet labels it machine-filled — in the reader's own language
  (`i18n.badge_body`) — and every signing line marked `*` shows the English one
  tap away (`i18n.risk_show_english`).
- **Every row names the form `de.json` uses.** Where a second form exists for the
  same concept, the row lists **every** string carrying it — as a counter-example
  (align it on the next pass) or as a same-root other sense (leave it alone). A
  glossary that breaks a dozen correct voting strings is worse than no glossary.
- **Register: formal *Sie*.** `de.json` addresses the reader as *Sie* throughout
  ("Geben Sie einen Kontonamen ein", `account.enter_name`; "Sperren Sie
  Sicherheiten", `account.margin_hint`). Do not "correct" a string to *du*.
- **Typography.** German quotes run „…", and the compound hyphen is a real
  hyphen: *Orderbuch*, *Limit-Order*, *Vesting-Saldo*, *Sicherheiten-Asset*. The
  file keeps the typographic „…"; an auditor who adds ASCII quotes back is
  regressing the file, not improving it.

Placeholders (`%(name)s`), URLs, object ids (`1.2.x`), asset symbols and theme
or network ids are **byte-verbatim** in every language and never appear here.

| wallet | Wallet | The local vault this app calls a wallet (`wallet.title` "Wallet", `auth.create_a_local_wallet` "Lokale Wallet erstellen", `common.wallet_locked` "Wallet gesperrt"), 190 strings. Align the seven onto Saldo on the next pass. |
| smartcoin | Smartcoin | A market-pegged asset (`asset.smartcoin_row` "Smartcoin", `asset.smartcoin_field` "Smartcoin-Symbol", `account.op_smartcoin_update` "Smartcoin-Update"), 21 strings. Same root, other sense and correct as they stand — the help prose introduces the family with the gloss *marktgebundenes Asset* (`help.topic_assets-mpa_body`, `help.topic_assets-mpa_text`), which describes the concept rather than renaming it. |

Same root, other sense and correct as they stand — the SINGULAR **Sicherheit** is this word declined, not a rival: `credit.collateral` "Sicherheit", `explorer.collateral_prefix` " (+Sicherheit ", and the compounds *Sicherheits-Asset*, *Sicherheitseinheiten*, *Sicherheitenbetrag* (`borrow.collateral_asset_symbol_or_1_3_x` "Sicherheits-Asset (Symbol oder 1.3.x)", `borrow.coll_units_tpl` "Sicherheiten (%(id)s Einheiten)", `borrow.collateral_amount_collateral_units` "Sicherheitenbetrag (Sicherheitseinheiten)"). One word in prose, the gloss in titles; not two words. Never "Liquiditätsreserve". Same root, other sense and correct as they stand — the shortened form owns these slots and they are right: `pool_net.col_pool` "Pool", `nav.pools` "Pools", `account.op_pool_create` "Pool-Erstellung". The hyphenated spelling `menu.p_pools` "Liquiditäts-Pools" and the run-together `pool.map_takeover` "im Liquiditäts-Pool-Netzwerk verwaist!" are the same word with two spellings of the link; follow the surrounding file rather than inventing a third. | stake | Stake | The locked balance that earns voting weight or a pool's yield (`pool.list_sub` "Stake ist eine Einzahlung beider Seiten für LP-Anteile.", `menu.d_tickets` "Vote-gesperrter Stake mit wachsendem Gewicht.", `help.topic_tickets_text` "Stake für Stimmgewicht sperren, das mit Lock-Zeit wächst."), 55 strings.
